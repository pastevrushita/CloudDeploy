# CloudDeploy

CloudDeploy is a simple Flask web application that I built and deployed using Docker and AWS EC2.

## 🛠️ Technologies Used

* 🐍 Python
* 🌐 Flask
* 🐳 Docker
* ☁️ AWS EC2
* 🐧 Linux
* 🔧 Git
* 📂 GitHub

## 🚀 What I Did

* Created a Flask web application using Python.
* Created a Dockerfile and built a Docker image.
* Ran the application inside a Docker container.
* Created an Ubuntu EC2 instance on AWS.
* Installed Docker on the EC2 server.
* Deployed the application on the EC2 instance.
* Configured port 5000 in the EC2 Security Group.
* Created a Python script (deploy.py) to automate Docker deployment.
* Uploaded the project to GitHub.

## 📁 Files

* app.py - Flask application
* dockerfile - Docker configuration
* requirements.txt - Python dependencies
* deploy.py - Deployment automation script

## 🌐 Running the Application
The application runs on port 5000.

http://<EC2-PUBLIC-IP>:5000
